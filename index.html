Hubungkan Google Apps Script

Backend API & Database Google Sheets

Salin URL dari menu Deploy > Manage Deployments > Web app URL (.../exec).

Syarat Akses Google Apps Script:
  • Execute as: "Me" (email Anda)
  • Who has access: Wajib dipilih "Anyone" (Siapa saja)
  • Pastikan URL berakhiran /exec (bukan link Google Sheets)
